## bit-hacks

Tool for testing bit-level C manipulation. Handles typical C expression syntax.

Try it here: https://andrewj31415.github.io/bit-hacks/

### Notes to self from development:

See https://tomassetti.me/antlr-mega-tutorial/ for antlr4 tutorial.
Also see https://tomassetti.me/antlr-and-the-web/ for the gradle script.

To build antlr4:
gradle generateParser

To build webpack:
npm run build

Currently, only webpack's build-dev works with antlr4.
